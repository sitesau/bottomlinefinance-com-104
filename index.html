A quote reflects risk, so vague briefs produce vague terms. Name the property type, location, realistic value view, the commercial use of funds, the position requested, the amount, and whether repayment is expected from sales, refinance or completion.

  • Position: senior debt, a bridging gap, mezzanine layer, second mortgage, caveat style requirement or development funding are different conversations.
  • Security: townhouse projects, commercial acquisitions, childcare sites, industrial assets and rural holdings each ask a different funding question.
  • Exit: state expected dates, because delay changes cost and sometimes feasibility.

Six categories, six different quote files

Do not send one generic request across every category. Private lending is broader commercial capital secured by property or another assessable asset. Construction funding follows a build program and releases draws as work is completed. Bridging finance covers a timing gap. Mezzanine finance sits behind senior debt. Development funding depends on the project sequence and presales or takeout path. Residual stock loans release equity after practical completion when product remains unsold.

Refinancing completed stock is not the same question as funding a live build, and both differ from capital needed to settle before another sale. Matching the category first keeps the quote relevant.

Assumptions to drag into the open

Ask which lender type is being approached, whether the facility is senior or subordinated, what security is required, what fees apply, and which events could alter the offer before settlement. Clarify the assumptions behind valuation, documents needed before approval, conditions precedent, and what happens if sales, refinance or completion run late.

  • Total cost: rate plus fees plus timing risk.
  • Equity protection: compare capital cost with return on equity and the cost of delay.
  • Next deal: a fast approval can still be poor value if it weakens the following transaction.

A simple quote stress test

Before accepting terms, test the structure against delay, valuation movement, slower sales and a longer refinance window. A cheaper option can increase timing risk; an expensive option can still protect equity if it settles cleanly. The practical rule is stark: no deal is better than a bad deal when approval solves today but damages tomorrow.

Common questions

Why can two quotes for similar amounts look so different? Because position, security, exit quality, timing and documentation differ. Senior debt, bridging, mezzanine, second mortgage, caveat style and development funding carry different risk, so the terms should not be compared like identical products.

What should be prepared before requesting indicative terms? Prepare the asset details, purpose, security position, amount sought, repayment path and expected dates. Add valuation assumptions, project numbers where relevant, and the category that matches the need.

Is lower pricing always better for an asset backed deal? No. A lower headline rate can come with tighter conditions, slower settlement or greater timing risk. The better test is total cost against return on equity, delay cost, equity protection and the effect on the next transaction.
